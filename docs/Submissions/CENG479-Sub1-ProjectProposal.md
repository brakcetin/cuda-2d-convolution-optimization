## Objective
Each 2-student team will propose a parallel algorithm-based solution for a computationally intensive
real-world problem. The proposal must identify a suitable problem, select a parallelization strategy,
and justify the approach with at least 3 peer-reviewed academic references.
Allowed Technologies  (select one)
•Java Threads — Multi-threading using Thread, Runnable, ExecutorService,
ForkJoinPool, etc.
•POSIX Threads (pthreads) — C/C++ shared-memory parallelism on Linux/Unix.
•CUDA — GPU-based parallel computing using NVIDIA CUDA.
## Project Requirements
•The problem must genuinely benefit from parallelization (sorting, matrix operations,
image processing, simulations, graph algorithms, etc.).
•Include a theoretical analysis of why the problem is parallelizable.
•Cite at least 3 peer-reviewed academic references (journals / conference
proceedings).
•Outline the expected speedup or performance improvement.
•Plan a comparison between sequential and parallel performance.
## Required Document Sections
1.Project Title and Team Members
2.Problem Statement — What computationally intensive problem will be solved?

3.Motivation — Why does this problem benefit from parallelism?

6.Performance Analysis Plan — How will you measure speedup?
7.Academic References — Minimum 3 peer-reviewed sources (APA format)
